우리 팀 사다리타기 - PWA 설치 방법

□ 파일 구성
  - index.html            : 앱 본체
  - manifest.webmanifest  : 앱 이름·아이콘·색상 정보
  - sw.js                 : 서비스 워커(오프라인 저장)
  - icons/                : 앱 아이콘 4종
  ※ 네 가지를 같은 폴더 구조 그대로 올려야 합니다.

□ 1단계: 웹에 올리기 (https 주소 필요)
  PWA는 https 주소에서만 설치됩니다. 파일을 더블클릭해 여는 방식(file://)으로는 설치·오프라인 저장이 되지 않습니다.

  ○ 방법 A. GitHub Pages (무료)
    - github.com 가입 후 새 저장소(Repository)를 공개(Public)로 만듭니다.
    - [Add file] → [Upload files]에서 압축을 푼 파일과 icons 폴더를 모두 끌어다 놓고 [Commit changes]를 누릅니다.
    - [Settings] → [Pages] → Branch를 main / (root)로 고르고 [Save]를 누릅니다.
    - 1~2분 뒤 https://아이디.github.io/저장소이름/ 주소로 열립니다.

  ○ 방법 B. 회사 웹 서버(사내망 포함)
    - https가 적용된 서버라면 폴더째 올리면 됩니다. 하위 폴더에 올려도 동작합니다.
    - 사내망 서버도 https가 아니면 설치·오프라인 저장이 되지 않습니다.

  ※ 회사 보안 정책으로 GitHub 접속이나 브라우저 앱 설치가 막혀 있을 수 있습니다. 이때는 정보보안 담당 부서에 확인하세요.

□ 2단계: 기기에 설치하기
  ○ PC (크롬·엣지)
    - 주소를 연 뒤 화면 위쪽 [앱으로 설치] 버튼을 누르거나, 주소창 오른쪽의 설치 아이콘을 누릅니다.
    - 설치하면 바탕화면·시작 메뉴에 '사다리타기'가 생기고 별도 창으로 열립니다.
  ○ 안드로이드 (크롬·삼성 인터넷)
    - [앱으로 설치] 버튼 또는 브라우저 메뉴의 [홈 화면에 추가] / [앱 설치]를 누릅니다.
  ○ 아이폰·아이패드 (Safari만 가능)
    - Safari로 연 뒤 [공유] → [홈 화면에 추가] → [추가]를 누릅니다.
  ○ 회의실 TV·대형 디스플레이
    - 안드로이드 기반이면 크롬으로, 윈도우 기반이면 크롬·엣지로 PC와 같이 설치합니다.

□ 설치 후 동작
  - 처음 한 번 인터넷이 연결된 상태로 열면, 이후에는 인터넷 없이도 실행됩니다.
    (첫 화면 제목 위에 '오프라인 사용 가능' 표시가 보이면 저장이 끝난 것입니다)
  - 귀여운 글꼴(Jua)은 첫 실행 때 인터넷에서 받아 저장합니다. 인터넷 연결 전에는 기본 글꼴로 보입니다.
  - 명단·기록은 기기마다 따로 저장됩니다. 사무실 PC 기록이 휴대전화에 보이지 않습니다.
  - 앱을 지우거나 브라우저 데이터를 삭제하면 저장된 명단·기록도 함께 지워집니다.

□ 내용을 고친 뒤 다시 올릴 때
  - sw.js 맨 위의 CACHE = 'ladder-office-v2' 숫자를 v3, v4처럼 올린 뒤 함께 올립니다.
  - 인터넷이 연결된 상태로 앱을 한 번 열면 새 버전으로 바뀝니다.
