효과는 프롬프트와 코드를 각각 복사할 수 있습니다. 폰트 링크는 눈누와 각 배포처로 연결됩니다.

UI·UX·모션·폰트 레퍼런스

UI·UX 디자인 스타일, 텍스트 모션, 입력 컨트롤, 커서 인터랙션, 무료 폰트를 직접 보고 움직여 본 뒤, 프롬프트나 코드를 그대로 복사해 쓰는 사전입니다.

UI·UX 디자인 13

화면 시안과 디자인 이미지를 만들 때 쓰는 스타일 프롬프트입니다. 주제, 구도, 색상 코드, 조명, 질감, 비율을 모두 담았고 스타일마다 제외 프롬프트(Negative)를 붙였습니다. 프롬프트 상자를 누르면 전체 내용이 펼쳐지고, 예시 보기 링크를 누르면 해당 스타일의 작품 검색 결과가 새 창에서 열립니다.

조합 예시 04

효과 여러 개를 한 번에 요청할 때 쓰는 프롬프트입니다.

무료 폰트

눈누 인기 무료 폰트 24종과 공유마당 인기글꼴 TOP20입니다. 버튼을 누르면 눈누 상세 페이지나 각 배포처에서 내려받을 수 있습니다.

눈누 전체 목록 ↗ 제목용 태그 ↗ 기본 고딕 태그 ↗ 영문 폰트 태그 ↗ 공유마당 인기글꼴 TOP20 ↗

미리보기는 구글 폰트로 제공되는 주아체·본고딕·본명조만 실제 글꼴로 표시하고, 나머지는 기본 글꼴로 보여 줍니다. 공유마당 TOP20은 매월 1일 갱신되며, 일부는 공유마당이 아닌 제작 기관 사이트에서 내려받습니다. 실제 모양과 상업적 이용 범위(라이선스)는 폰트마다 다르므로 각 배포 페이지에서 확인하세요. 분류는 참고용이며 목록 기준일은 2026. 11. 24.입니다.
